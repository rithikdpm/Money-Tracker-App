# Money Tracker (Android)

A simple, offline money tracker for Android. Track the money you receive (credit) and the money you pass on (debit), and always see your available balance. All data is saved on your phone, so no internet or server is needed.

Built with HTML, CSS and JavaScript, and packaged as an Android app using Capacitor.

> The Spring Boot + MySQL web version of this project is here: [money-tracker-spring-boot](https://github.com/rithikdpm/money-tracker-spring-boot)

## Download

Get the latest APK from the [Releases page](https://github.com/rithikdpm/money-tracker-android/releases/latest).

**How to install**
1. Download `money-tracker.apk` on your phone
2. Open the file and tap **Install**
3. If Android asks, allow **Install unknown apps** for your browser or file manager

## Features

- Available balance that is always calculated correctly (credit − debit)
- Add (+) or deduct (−) an amount with an optional note, such as sales or loan
- Call-history style transaction list with ↙ credit and ↗ debit arrows
- **All / Credit / Debit** filters (All is the default)
- A debit cannot be more than the available balance
- Delete a wrong entry (blocked if it would make the balance negative)
- Works fully offline, data stays on your device
- Mobile-first design

## Tech Stack

- HTML, CSS, JavaScript
- Capacitor (Android packaging)
- localStorage (amounts stored in paise, so calculations are exact)

## Project Structure

```
money-tracker-android

├── android/              # Android Studio project (generated by Capacitor)
├── capacitor.config.json
└── package.json
```

## Build it yourself

1. Install Node.js (LTS) and Android Studio
2. Clone the repo and run:
   ```
   npm install
   npx cap sync
   npx cap open android
   ```
3. In Android Studio, run the app on an emulator or phone, or build the APK with
   **Build > Generate App Bundles or APKs > Generate APKs**
4. The APK is created at `android/app/build/outputs/apk/debug/app-debug.apk`

After changing anything inside `www/`, run `npx cap sync` again and rebuild.
